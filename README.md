## Currently building

### BMG Gym System &nbsp; `In development`

A web-based gym management system built with a distributed architecture and production-grade design decisions.

**Architecture highlights:**

- **Edge node** — JavaFX desktop app with embedded SQLite for attendance tracking. Supports offline operation and differential sync with the backend via audit fields and scheduled jobs.
- **Identity-based security** — JWT authentication with stateful refresh token rotation and RBAC authorization. Permissions are embedded in the token payload for granular module-level access control.
- **Configurable anomaly detection** — Access rule thresholds (scan frequency, time windows, daily limits) are parameterized via environment variables, following 12-Factor App principles (Factor III).
- **Business Intelligence** — Revenue and loss reports by period, annual trend analysis, client investment ranking, and plan performance analytics.

`Java` &nbsp; `Spring Boot 3` &nbsp; `PostgreSQL` &nbsp; `Angular v20+` &nbsp; `JavaFX` &nbsp; `Railway`
